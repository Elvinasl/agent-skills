# agent-skills

Reusable skills for Claude (Claude Code, the Claude app) and other coding agents.
Each skill is a `SKILL.md` file — plus any templates and scripts it needs — that teaches the agent a specific way of working, so it writes code the same way every time.

## Skills

| Skill | What it does |
|---|---|
| [`spring-boot-house-style`](plugins/spring-boot-house-style/skills/spring-boot-house-style/SKILL.md) | Opinionated Spring Boot 4.1 / JDK 21+ code conventions, with a scaffolder for new services. |

### spring-boot-house-style

Distilled from three production Spring Boot services and updated for Spring Boot 4.1 (Jackson 3, Hibernate 7, Spring Framework 7). It covers application code only — deployment and infrastructure are out of scope.

**New services** are generated by a bundled script from real template files, so every project starts identical:

```bash
bash scripts/scaffold.sh --name order-sync --package com.acme.ordersync \
  --db postgres --with rabbit,jobrunr,sentry --java 21
```

You get a Gradle build on Spring Boot 4.1 with an `integrationTest` source set, `dev` / `remote` / `test` profiles, UTC `Clock`, JPA auditing, CORS, locale resolution, one error-response shape with a validation handler, Testcontainers `@ServiceConnection` tests, and a local `docker-compose.yml`. Optional modules: PostgreSQL or MySQL, RabbitMQ (exchange + DLQs, retry, MDC cleanup), JobRunr, Sentry.

**When extending a service**, the agent follows these rules:

- **Layout and naming:** feature-first `snake_case` packages; entities without an `Entity` suffix; `XxxRequest` / `XxxResponse` / `XxxView` DTOs; single-role services (`PuzzleRestarter`, `XxxMapper`, `XxxProcessor`); plural kebab-case REST paths.
- **Lombok:** which annotations go on beans, entities, DTOs, events, exceptions and properties classes, plus the pitfalls (`@Builder.Default`, no `@Data` on entities).
- **Persistence:** audited `created_at` / `updated_at`, plain-id references, `@JdbcTypeCode(SqlTypes.JSON)` columns, `@Version`, tenant-scoped repository methods, `Specification` filters, advisory locks for create races.
- **Flyway:** `V{yyyy.MM.dd}_{HH.mm}__create_table.sql` naming, `R__` views, constraint and index naming, PostgreSQL and MySQL templates.
- **Errors and i18n:** one exception per failure case, `ErrorResponse` + `ErrorId`, `@RestControllerAdvice` handlers, no catch-all handler, translated messages.
- **Messaging:** RabbitMQ topic exchange with a DLQ per queue, retry with backoff, publish only after the DB commit, multi-stage webhook pipelines.
- **Integrations:** declarative HTTP service clients with timeouts, "200 with errors" checks, HMAC-verified webhooks, service-to-service secrets.
- **Security:** stateless filter chain, JWT / API-key filters, `@CurrentUser`, role meta-annotations, tenant ids only from the principal.
- **Configuration:** what goes in each profile file, typed `@ConfigurationProperties`, secrets only from environment variables.
- **Testing:** what must be tested, unit-test and integration-test patterns, `@MockitoBean`.
- **Boot 3 → 4:** a table of what changes when you upgrade an older repo.
- **Code style:** minimal comments (Javadoc only for a non-obvious *why*), one-line lowercase imperative commit messages.

In an existing repo, the skill tells the agent to match that repo's conventions first.

## Install

### Claude Code: plugin marketplace (recommended)

Inside a Claude Code session:

```
/plugin marketplace add Elvinasl/agent-skills
/plugin install spring-boot-house-style@elvinasl-skills
```

Or from your shell:

```bash
claude plugin marketplace add Elvinasl/agent-skills
claude plugin install spring-boot-house-style@elvinasl-skills
```

Claude loads the skill automatically when you work on a Spring Boot project. You can also call it explicitly with `/spring-boot-house-style:spring-boot-house-style`.

### Claude Code: copy the skill folder

For all your projects:

```bash
git clone https://github.com/Elvinasl/agent-skills.git
mkdir -p ~/.claude/skills
cp -r agent-skills/plugins/spring-boot-house-style/skills/spring-boot-house-style ~/.claude/skills/
```

For a single repository, copy the folder into that repo's `.claude/skills/` instead, and commit it so your team gets it too.

### Claude app (claude.ai / desktop)

1. Zip the folder `plugins/spring-boot-house-style/skills/spring-boot-house-style` (the zip must contain `SKILL.md` at its top level).
2. Upload it as a custom skill in the app's skill settings.

### Other agents

`SKILL.md` is plain Markdown with a short YAML header, and the scaffolder is a plain Bash script. Point any agent that reads instruction files (for example via `AGENTS.md`) at the skill folder.

## Example prompts

- "Create a new Spring Boot service called `order-sync` with Postgres and RabbitMQ."
- "Add a `teaser_invites` table, entity, repository and an endpoint to create one."
- "Publish an event when an invoice is parsed and consume it in the export feature."
- "Add a nightly job that cleans up expired rooms."
- "Call the exchange-rates API from the billing feature."

## Requirements

JDK 21+, Docker for the local database and integration tests, and Bash + Perl for the scaffolder (present on macOS and Linux).

## Contributing

Issues and pull requests are welcome. If a rule doesn't fit your project, open an issue describing the case. The skill is opinionated on purpose, but rules that are unclear or wrong should be fixed.
